
 # ReLoop – AI-Powered Reuse and Resale Platform

ReLoop is an AI-powered platform designed to make the reuse of items during student move-outs easier, safer, and more efficient. It connects sellers, students, and repairers through a centralized platform, helping reusable items find their next users instead of being discarded.

During move-outs, many useful items are abandoned or sold without sufficient information about their dimensions, defects, condition, or pickup deadlines. This creates difficulties for buyers, repairers, and residential associations. ReLoop addresses these challenges by using AI to structure item listings, improve matching, and manage pickup deadlines.

## User Roles

ReLoop provides four different role-based views:

- **Admin:** Verifies seller accounts, manages listings, and monitors platform activities.
- **Seller:** Creates an account, gets verified by the admin, and lists reusable items.
- **Student:** Can browse available items, request items, find matches, and communicate with sellers without creating an account.
- **Repairer:** Can discover items suitable for repair, request items, and communicate with sellers without creating an account.

## Key Features

- AI-powered item listing and information structuring.
- Matching of students and repairers with suitable items.
- Seller verification through the admin.
- Four role-based interfaces with different access permissions.
- In-app chat to coordinate transactions without exposing personal contact information.
- Pickup deadline tracking and automated warnings.
- Automatic re-listing of items when they are not picked up after two warnings.
- Item condition and defect information to support informed decisions.

## Technology Stack

- **Frontend:** React.js, Vite
- **Backend:** Python
- **Database:** SQL-based database
- **AI:** AI-powered listing structuring and matching

## Objective

The main objective of ReLoop is to promote a circular reuse ecosystem by reducing unnecessary waste, making affordable items accessible to students, supporting repair opportunities, and ensuring safer and more organized move-out management.
